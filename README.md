# HousekeepingWeb

HousekeepingWeb 是一個家政服務電商平台，連結雇主與家政人員，提供發包、接單、評論、訂單管理等功能。系統支援 Google 登入、購物車、金流串接、RWD 響應式設計，並具備 Admin 後台管理功能。

## Tech Stack
Next.js 14 · Supabase · Vercel · Tailwind CSS · Zustand · TypeScript

## 開始開發
```bash
npm install
cp .env.local.template .env.local
npm run dev
```
